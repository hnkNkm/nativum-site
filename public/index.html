Modern UI, by the Web Platform.

Nativum は、JavaScript ランタイムや依存パッケージなしでモダンな Web UI を構築する Passive Native Web UI System です。HTML そのものがコンポーネント API であり、 ブラウザが UI ランタイムです。

設計原則

Native First

ブラウザに適切なネイティブ機能があれば、必ずそれを使います。ボタンは <button>、モーダルは <dialog>、開閉は <details>。再実装しません。

Security by Absence

依存関係を監査して安全にするのではなく、依存関係そのものを存在させません。Core の下に第三者の実行可能な依存グラフはありません。

Semantics over Features

実現できる UI の数より、正しい HTML の意味論を優先します。ネイティブで実現できない UI は、CSS hack で再現せず提供しません。

Progressive Enhancement

高度な CSS 機能は「後付け」で強化します。対応していない環境でも、コンテンツと基本操作は必ず維持されます。

コンポーネント

アコーディオン

実行時に JavaScript はありますか?

ありません。Nativum Core は HTML と CSS のみです。

依存パッケージは?

ありません。npm などで配布する場合も dependencies は空です。

フレームワークと併用できますか?

React / Vue / Astro などからも class を付けるだけで利用できます。

導入

nativum.css を読み込むだけです。ビルドステップもインストールスクリプトもありません。

  1. Release から nativum.css を取得する (git clone / vendoring / npm など、配布方法は自由)
  2. サイトの静的アセットとして配置する
  3. HTML に <link> で読み込む
<link rel="stylesheet" href="assets/css/nativum.css">
ホスト側の JavaScript (React など) は禁止されません。Nativum は JavaScript を「要求しない」だけです。

FAQ

実行時に JavaScript は必要ですか?

不要です。Nativum Core は HTML + CSS のみで構成され、実行時の依存グラフはゼロです。

React / Vue などのフレームワークと併用できますか?

できます。Nativum はクラス名を適用するだけの passive な CSS 設計システムです。既存のアプリに新たな UI ランタイムの依存は追加しません。

配布方法に制限はありますか?

ありません。Git clone / vendoring / GitHub Releases / npm / JSR / Cargo / CDN など、どの形式でも同じ nativum.css として動作します。

タブ UI は使えますか?

提供していません。タブはネイティブの HTML primitive が存在しないため、radio hack などの CSS hack で再現しない方針です。

ダークモードには対応していますか?

対応しています。OS の設定に合わせて light / dark を自動切替します。サーバー側で data-theme 属性を使って明示的に強制することもできます。

ライセンスは何ですか?

MIT です。商用利用を含め自由に利用できます。
